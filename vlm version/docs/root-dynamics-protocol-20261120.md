# 固定 reference / 已对齐执行器的根部诊断（2026-11-20）

基线：`dynamics-actuator-20261119-r1` 五组；当前 162 文件保存在 `snapshots/dynamics-before-root-20261120`。本轮不改 VLM、Kimodo、IK、reference、SONIC 权重、29 个已对齐执行器参数或手指控制，默认后端不变。

| 因子 | 原地面 | 加诊断支撑面 |

支撑面是 1×1×0.1 m 静态台，其顶面为初始参考脚位均值减去核验的 0.035 m 脚底深度，约 0.0208255 m。高度依据参考和碰撞几何预先确定，不按新运行误差调参。它改变接触环境，是物理一致性反事实，不是恢复真实训练环境，也不是原场景性能改善。不会平移参考、机器人根部或腕目标。初始根姿态/关节、时序、实际消费参考和执行器均须核验不变。

保留自碰撞、手部活动自由度、摩擦、求解器及其他身体质量/COM/惯量，不将这些变量一并改为训练配置。现有阻尼、求解器 8/4 等相同；公开训练 self-collision=True 与 Arena False、固定手与 14 活动手指等差异作为审计限制保留。

指标：到达后 1.2–8 s 根部 XYZ 有符号偏差、水平/竖直/三维均值、姿态角、双腕均值/p95/max 与全部记录帧双腕 3 cm；4–8 s 足部位置/支撑、腿部与根姿态贡献、下肢静差及实际−参考误差。使用 feet-root 运动学恒等式分解，验证 XML 与仿真脚位一致。消费参考逐帧相同，400 控制帧/1600 物理步。
