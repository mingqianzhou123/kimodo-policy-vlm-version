# VLM 两尺度局部定位与异常核验

## 固定范围与预先确定的方法

保留上一版 135 个文件于 `snapshots/vlm-before-refinement-20261118/`，旧九组结果 `runs/vlm-stability-20261117-r1` 不覆盖。Kimodo、IK、SONIC、历史条件、重规划、相机、场景布置、深度反投影及 15 cm 工作区门限不改；夹爪打开、motion text 条件仍关闭。

改动限定在图像定位入口及评估记录：

1. 使用相同 Qwen3-VL-4B、BF16、确定性解码和原整图提示词获得粗点。
2. 每只手分别围绕粗点裁剪 192×192 与 256×256 原图区域，边界处平移裁剪框以保持尺寸；放大到 640×640。每个裁剪单独请求对应颜色方块的中心，返回裁剪内 0–1000 坐标。无标记返回 null。
3. 将两个预测映回原图。两点距离超过 6 px 则拒绝。对两个点及其平均点分别检查原始 RGB 3×3 邻域：至少 5/9 像素的目标颜色通道 ≥80，且 ≥1.5×(其他通道最大值+1)。不满足则拒绝。
4. 两个 VLM 点的平均值作为最终坐标；**不使用颜色质心、颜色吸附、真值坐标替换或放宽原有深度/工作区门限**。颜色仅用于验证当前红/蓝标记任务，不能视作通用物体识别器。
5. 保存所有原始输出、裁剪图、裁剪坐标映射、两尺度差异、颜色核验和拒绝原因。即使被新核验拒绝，也保留候选坐标用于离线误差统计。

阈值在新九组执行前固定，本轮不按逐组结果调参。一次定位包含 1 次整图 + 4 次裁剪生成；每个条件仍重复定位三次，以检验同图重复性。更慢的多次推理是本方法的成本，本轮不优化速度。

## 对照与统计

复用相同九个位置/视角、seed 1000、400 帧/8 秒和到达期限 1.2 秒。视觉误差、IK 后参考残差、实际跟踪误差及端到端误差分别统计。条件接受/拒绝均计入，不挑选重复推理中的最好结果。

比较同时报告：全部九组的视觉误差和拒绝情况、双方都执行的配对条件、各版本所有已执行条件。不能把新旧不同接受集合的平均数当成严格配对改善。

这九组是已知回归条件，不是未见场景泛化测试。额外复用一个真实无标记旧帧检查拒绝行为，不进行动作执行。

## 实测结果

九个条件全部完成，9/9 接受、9/9 执行，每组 400 帧，共 3600 个 50 Hz 控制帧。27 次完整定位包含 135 次模型生成。模型未训练或换权重；改动是两尺度局部定位与异常核验。

**视觉精度改善成立，但端到端仍未全部稳定达到双腕 3 cm。** 新九组左/右视觉误差均值为 **0.49 / 0.48 cm**，最大值为 **0.87 / 0.78 cm**。严格要求到达期限后全部 340 帧双腕同时 ≤3 cm，新版通过 **4/9**，旧版 **1/9**。这不是抓取成功率。

### 与旧版相同已执行条件的配对结果

双方共同执行 7 个条件，每条件等权。数值为左/右，单位 cm；跟踪与端到端采用 1.2 秒到达期限后的均值。

| 误差层 | 旧版 | 本版 |
|---|---:|---:|
| 视觉定位 | 1.55 / 2.74 | 0.52 / 0.46 |

新九组全部已执行条件的跟踪均值为 1.98 / 2.91 cm，端到端均值为 2.24 / 2.52 cm。它们的分母与旧版七组不同，不替代上面的配对表。

### 同图对照、重复性与异常核验

- 新旧 RGB 逐字节相同的条件为 0/9；整图粗点复现旧版为 7/9。对照场景几何与后端一致，但重新渲染不是完全相同输入。
- 同一新 RGB-D 帧的整图粗点与精定位统计保存在 `comparison.json` 的 `same_frame_common_valid_visual_by_hand_cm`，包括可反投影数量及异常值，避免将渲染差异归于算法。
- 同帧可反投影点的定位均值：左手 9 对 **1.59 → 0.49 cm**，右手 8 对 **12.98 → 0.50 cm**；右手均值包含 84.53 cm 的地面误指，其中位数为 **2.98 → 0.51 cm**。另外 1 个右手粗点深度拒绝，精定位后为 **0.29 cm**，单独记录，不填零。
- 9/9 条件中，三次完整定位的全部五次模型原始输出分别一致；这只是确定性同图重复性，不是 27 个独立场景。
- 真实无标记旧帧返回“目标不可见”并拒绝，没有动作执行。离线将旧版 18 个预测点交给 RGB 核验，7 个不在相应颜色标记上的点被拒绝；包括原位左移误指手部、近目标左移误指地面的两个典型异常。这个回放不等于在线异常识别准确率。
- 新九组均通过核验，因此本轮没有充分测得复杂遮挡、同色干扰物等情况下的误报/漏报率。核验依赖红/蓝标记语义，不能直接当成自然物体检测器。
- 新版每次完整定位需要 5 次生成，首次定位的生成与解码累计平均 3.53 秒；含裁剪等处理的 `inference_s` 平均 3.92 秒，均不含模型加载。这是共享开发机观测值，本轮未做速度优化。

## 复现入口与同图控制

在开发机 `/root/workspace/humanoidVLA/vlm version` 中：

```bash
PYTHONPATH=. ../cross_tracker/data/cache/envs/policy/bin/python scripts/run_vlm_stability.py \
  --suite-id vlm-refined-20261118-r1 --policy-gpu 6 --sim-gpu 7 --vlm-localizer refined
PYTHONPATH=. ../cross_tracker/data/cache/envs/policy/bin/python scripts/audit_vlm_stability.py \
  runs/vlm-refined-20261118-r1
PYTHONPATH=. ../cross_tracker/data/cache/envs/policy/bin/python scripts/compare_vlm_stability.py \
  runs/vlm-stability-20261117-r1 runs/vlm-refined-20261118-r1
```

已存在的 run ID 不允许覆盖；重跑时使用新 ID。`--vlm-localizer baseline` 保留原整图路径，默认也仍为 baseline；新路径须显式指定 refined。

原实验仿真 GPU 为 1，本轮因共享开发机资源占用使用 GPU 7，推理 GPU 仍为 6。场景、相机、初始腕位置、权重、源码与控制参数按运行记录核验。重新渲染的 RGB 不保证逐字节一致，因此额外用每次新推理记录里的 `coarse_intent` 与最终 `intent` 在**同一 RGB-D 帧**上比较。它们使用相同真值、深度反投影和模型；粗点就是原整图提示词的输出，不另外构造伪基线。`comparison.json` 同时保留 RGB 差异、粗点是否复现旧结果、同图粗点与精定位误差。

旧点颜色核验回放属于离线组件检查，不是新的模型调用或仿真成功率；无标记预检也不计入九组条件分母。
