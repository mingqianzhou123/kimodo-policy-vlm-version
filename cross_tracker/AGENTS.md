# Cross Tracker 工作约定

- 本目录是跨 tracker 工作的唯一新增文件入口。原始数据和历史审计只读，共用仓库通过路径引用。
- 先读 README.md、docs/status.md；先核对真实训练/评测入口，再修改代码。不要盲用已有 BiGym 或 Kimodo 调参启动脚本。
- 不复制整套模型/环境，不为未发生的需求建立框架；入口短、职责单一、命名直接。接近 200 行时先检查是否承担过多职责，不为了行数压缩可读性。
- 每次运行独立 run_id，保存实际配置、数据清单、代码版本/修改、seed、命令、平台、日志与评测。禁止覆盖已有运行。
- 数据按整条轨迹划分，训练和验证不得共享轨迹；所有方法使用固定名单。归一化只用训练来源的训练集，留出 tracker 不参与。
- 必须使用修正标签和可用帧掩码，窗口不得跨越排除帧或轨迹边界。待核验不等于成功或失败。
- 未核验的视频、接口、环境和运行状态如实记录，不把静态检查通过写成模型已跑通。
- 正式训练前完成数据读取、图像对应、小批量过拟合、单源短程和评测接口检查。算力使用当前用户指定平台，不再连接退役 A800。

- 百度开发机仅使用用户明确指定的 T2M-PLUS（dv-e21ddf3a87）；不是 T2M 或 Rethink-humanoid。进入终端前核对实例名和ID，不能凭名称相近或目录猜测归属。
