# 上层策略依赖性与最小复核（2026-11-15）

用户提出：跨tracker混训现象是否只是Kimodo的特点，是否需要π0.5或其他上层策略对照。以下是研究建议，不代表已授权新增π0.5训练或已完成接入。

必须区分两个轴：同一Kimodo下有/无pt_419h检验示教策略预训练的影响；Kimodo与不同策略家族检验结论在另一种实现上能否重复。用户已选择的“scratch”仍保留冻结运动先验、视觉/文本预训练以及从运动先验复制的ControlNet层，不能排除Kimodo结构和运动先验的影响。

建议保留Kimodo主实验；第二骨干优先考虑π0.5。CCT原论文使用π0.5，公开openpi提供训练/推理实现及预训练权重，因此有助于把CCT从Kimodo特有适配中分离出来。但π0.5下的人形任务、控制器和动作接口仍是适配，不能直接宣称完整复现原论文。

最小复核先限定箱子、两tracker、一seed：π0.5单SONIC、单TWIST2、双源朴素混训，以及双源CCT，共4组；先证明同tracker单源能学会再解释混训结果。初筛后再补必要的seed和任务，不立即扩成所有任务、初始化与骨干的笛卡尔积。若论文要主张新方法有跨骨干收益，还要在第二骨干加入新方法，并和同骨干朴素混训/CCT比较。

主比较是每个骨干内部的变化：双源对目标单源的增益、单源跨tracker迁移的变化、条件化方法对朴素混训的增益。两个骨干绝对成功率的高低同时受到预训练数据、参数规模、动作表示、历史观测和优化配方影响，不能全部归因于tracker或架构。

实现注意：openpi默认action_dim=32，当前tracker外部接口是40维，接入需处理动作输入/输出投影及checkpoint兼容性，不能截断后8维。Kimodo使用自己的运动表示，外部同40维接口不等于内部训练目标相同。应固定示教名单、目标tracker、场景seed、动作语义/坐标系/时间对齐、观察与执行协议；无法完全匹配的观测历史、内部表示及预训练差异单独报告。骨干内保持优化配方和数据预算一致，骨干间不以机械相同步数作为充分训练证据。
