## 执行与记录规则

两个任务先各训到 30k，仍使用 101k 步学习率调度。各评 25k/30k，验证种子起点 700000，每 checkpoint 50 回合。两任务完成后，无发散才继续同一 run 到 101k，并验证 80k–100k 五个 checkpoint。发散或运行失败会停止执行队列。官方测试种子 620000 尚未使用。

稳定组合是学习率减半、AdamW β2=0.95、尖峰跳过因子 5。单种子只验证组合是否可用，不估计发散概率，也不能归因到单个改动。

发散判据沿用 `scripts/diag/loss_spikes.py`：2000 步之后，连续 10 个日志点（50 步一次）的运动损失中位数 >0.5。单点尖峰不算发散。

每个新参数组合使用新实验 ID 和新 run 目录，记录父实验、改变了什么、为何改变。续训沿用原 ID，记录阶段变化。原始证据保留在 config.json、metrics.jsonl、train.log 和 val700000 结果文件中。

历史来源为 `docs/benchmarks/bigym2.md` §6–10。历史精确日志未迁移的字段留空；历史参数方案依文档与当前配置还原。第一套评 26k–30k 五个 checkpoint，第二套评 80k–100k 五个 checkpoint，各 100 回合。中途测试集最高值仅参考，不能当主结果。历史官方结果与新验证结果不能直接宣称同口径提升。

空白表示未测或来源未记录，不等于 0。秒/步是最后 5 个日志窗口的中位数；显存是采样峰值，不是分配器精确峰值。Excel 不自动联网刷新。
