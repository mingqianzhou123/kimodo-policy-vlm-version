# BiGym 2.0 实验总表

每跑完一个实验就在这里加一行。用途：按「所有任务共用一个步数、9 个任务平均最高」挑配置和步数（规则见 [bigym2.md](bigym2.md) 第 10 节）。
数字都是成功率（%）。**空格表示没评过，不是 0。** 过程、原因和日志位置写在 bigym2.md，这里只放配置和成绩。

最后更新：2026-11-19。

权重衰减 0.01、梯度裁剪 1.0、bf16、每次预测 50 帧。下表只列不同的地方。

  只知道 move_plate 是 60k（100k 时掉到 10）、dishwasher_close 在 20k–50k 之间学会。

  加 RTC（重叠 40 帧）回到 50、18，只追平默认设置（54、26）。
