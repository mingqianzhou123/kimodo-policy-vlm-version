# Fullbody v1 E20

本目录保留成功率 **16.28%（293/1800）** 版本的代码说明、最终结果及小型数值证据。没有打包 checkpoint、训练缓存、测评视频、逐步轨迹、旧 v2 版本或后续推理消融。完整本地运行产物保留在忽略的 `log/` 下。

## 修改内容

1. **所有真实切点可采样。** 不再要求切点后有完整50帧。未来不足时先保持最后的目标姿态、根位置、朝向和手目标，再统一提取特征；不重复最后一个运动特征向量，也不继续积分末帧非零导航速度。真实观测、图像和样本计数不随目标补齐增加。保留 ToolBook 的目标右移语义，并额外保留最后一条动作命令。
2. **历史全部来自实测。** 仿真每控制步采集 `state_history[N,32]`、`body_q_history[N,29]`、`base_pose_history[N,7]`，下次请求传完整增量。adapter禁止用此前ActionChunk补历史，校验长度、有限性及新旧字段一致性；reset/成功请求后同步清理。
3. **完整29关节反馈。** 训练读取 `observation.state[:29]`，仿真读取真实关节位置。按关节名字从录制顺序转模型顺序，不在adapter里猜腿角。历史条件为heading两维及34个骨架节点全局旋转，共206维。底层WBC仍负责腿部控制，29维输入不等于29关节直接执行。
4. **沿用v1切点语义。** 历史区间 `[cut-100,cut)`，RGB位于当前切点；最新实测进入缓存，随后成为历史。不将当前实测运动、骨盆高度或连续手状态硬固定为预测第0帧，也不新增当前帧姿态条件。`condition_current_observation=false`。
5. **图像共同直接缩放。** 训练与推理共用RGB uint8→双线性antialias→224×224；640×360直接缩放，取消letterbox黑边。宽高比会被拉伸，这是该版本采用的参考语义；没有声称保持原比例。
6. **预测50、执行20。** 模型30Hz、控制50Hz，按累计绝对端点分配控制步，33/34/33循环，避免每段固定33步产生累计错位。RTC=0，使用exact时间解码、operator转向和ToolBench手形模板；不包含后续原始插值/零转向/SIMPLE输出模板诊断。

## 训练设置

入口 `configs/toolbench_fullbody_v1_e20.yaml`：600000 optimizer steps、seed1000、18条件task_uniform采样、global batch128、四卡每卡32、BF16、math attention、100帧历史、50帧预测。冻结运动先验、视觉与文本编码器；任务ControlNet和连续手头从零训练，不载入任务策略checkpoint。

AdamW betas=(0.95,0.999)、weight decay=1e-6；ControlNet backbone学习率1e-5，adapter/hand为3e-5；warmup1000、cosine decay600000、最低比例0.1。当前配置继承通用tuning配置并显式覆盖600k设置，不再依赖旧v2配置文件。

正式成绩只使用最终checkpoint_600000，不将中间checkpoint平均或拼接。首次训练通过门检后，按用户要求跳过中间固定验证集评测，训练完成再做正式评测。
