# 原地面稳定支撑初始化协议 · 2026-11-23

比较五个固定手部世界目标。旧组使用 `dynamics-actuator-20261119-r1` 的实际状态和消费参考。新组在同一原地面、原始传感器质量和对齐执行器上重新生成 Kimodo + IK-hold 参考。两组均使用发布版 SONIC。逐案归档目标取自 `vlm-refined-20261118-r1`，包含双腕、两个虚拟手端和腕的世界朝向。真值标记按原始重置姿态创建，只供评测。

## 初始化与交接

1. 在初始姿态创建该案的红蓝标记，并按原案设置相机横移。记录标记真值，之后将其同旧场景逐项比较。
2. 用原版 SONIC 跟踪初始站姿，夹爪指令为零。首个物理步沿用既有执行器对齐流程。每次 20 ms，检查双踝各自竖向净接触力 >10 N、踝中心 z 距 0.035 m 在 5 mm 内、各脚线速度 <0.01 m/s、根部线速度 <0.02 m/s、根部角速度 <0.10 rad/s、根高 >0.65 m、根部倾角 <15°。连续 25 帧满足才交接。250 帧超时记为失败，保留日志。脚底几何依据上一轮的精确 USD 审计。
3. 保留 SONIC 的运动历史和物理状态，以此刻实测 XY、姿态重新建立参考坐标系，清空上一条站姿参考载荷。首个任务请求取此刻实测根部、双踝和双腕，启动新的任务历史与 1.2 s 到达时钟。根部和双踝支撑由原有 OraclePolicy 与 IK 消费。
4. 从落地后实测手位置按原五次插值到归档世界目标，保持归档腕朝向。复用原先一次视觉定位的结果；目标位置、方向和真值标记独立核对。归档的视觉结果只由策略读取，标记真值只用于评价。
5. 记录任务的 400 个控制帧和 1,600 个物理步。开始的 5 个控制帧沿用原策略积累历史时的站姿指令，随后按原有 25 帧动作块交接。落地预热单独记录。核对实际消费的参考与发送的世界根位、关节、腕位；输出到独立 run 和 fixtures 目录。

## 指标

沿用旧基线到达后窗口，任务相对时刻大于 1.2 s（浮点容差 1 μs）至 8 s，50 Hz 下共 340 个采样。分别对实际−参考、参考−视觉目标、实际−视觉目标、参考−真值标记、实际−真值标记计算双腕世界距离。逐腕给出均值与最大值。每一种口径都单独要求 340 帧左右腕同时 ≤3 cm。根部位置报告有符号 XYZ、三维距离和各轴绝对峰值。姿态报告相对旋转角和世界系欧拉角，同时统计双脚世界跟踪以及用各自根位姿变换后的双脚、双腕误差。沿用原分析脚本在 4–8 s 分解足位、根姿态和下肢关节对根部前移的贡献。
