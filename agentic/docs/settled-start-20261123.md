# 原地面落地后初始化 · 五案验收

**五个原失败案例全部通过严格的双腕 3 cm 标准。** 在真实执行的 2,000 个任务控制帧中，到达后的 1,700 帧全部满足双腕相对消费参考、归档视觉目标和真值标记的三种验收口径。实际到真值标记的五案均值为左 1.084 cm、右 1.109 cm，最差帧为 base-center 左腕 2.445 cm。旧对齐执行器基线在相同口径下通过 0/5。

## 支撑参考修复了多少

五案均在原地面预热 95 帧（1.90 s），其中最后 25 帧连续稳定。交接时根高 0.777510 m，左右踝高 0.0350004 / 0.0350003 m，竖向接触力 194.45 / 183.75 N。将上一轮 USD 脚底几何的八个顶点变换到此刻实测踝位姿，最低点距地在 0.002 mm 内，原先悬空 2.083 cm 的几何矛盾已消除。五案第 4–8 s 的全部记录帧均为双脚承重。

到达后根部 XYZ 有符号均值由 **(+1.130, −0.584, −2.418) cm** 变为 **(+0.641, −0.308, −0.161) cm**。竖直偏差绝对值减少 2.257 cm（93.3%），根部三维平均跟踪误差由 2.785 降至 0.810 cm（减少约 71%）。双腕世界跟踪均值从 2.526 / 2.899 降到 0.950 / 0.935 cm。右腕相对根部的局部误差均值由 0.608 升到 0.808 cm，全局改善不能解释为每个局部关节都跟得更准。

## 前倾是否需要单独排查

旧参考平均世界 pitch 为 0°，实测为 1.745°。新参考保留了落地站姿的 **2.055°**，实测平均 **2.508°**，比新参考多前倾 **0.453°**。绝对前倾有所增加，相对参考的额外前倾大幅缩小。4–8 s 的运动学分解中，根姿态对根部前移的贡献从 +2.277 降至 +0.569 cm，新组根部总前移为 +0.596 cm，双脚水平位置范围最大 0.00077 cm。上述分解说明误差表现在哪些姿态分量上，动力学成因仍待独立证据。

**本轮可按双腕要求验收。** 若后续任务要求更直立的绝对躯干姿态，或更小的水平根部漂移，再用独立实验区分预热站姿本身与任务期间额外前倾。本轮到此结束，保留原刚体质量和对齐后的增益。
