# 实验 5：拆原因

状态：未开始。只在实验 4 通过后做，按实验 4 的结果走对应的一支，只做一支。

## 问的是什么

主导环节的缺口，是因为缺哪一项信息；便宜的办法能否补上；如果不能，需要学什么。

## 主导环节是第 1 类（站位或姿态）

- 伸手类做两因素表。决策来源：VLM；VLM 加几何可达性工具；示教目标。生成器：运动学规划器；Kimodo（文本加稀疏关键帧约束）。
- 三个主对比：几何工具补上多少；同一生成器下几何工具离示教目标还差多少；给定示教目标时 Kimodo 能否生成可执行动作。
- 腿部类比较三种动作来源：示教片段检索、稀疏关键帧模板、Kimodo 稀疏约束生成，记录各自需要的人工量。

## 主导环节是第 2 类（关键部位的目标）

- 决策来源三档：VLM；VLM 加一个由物体几何给出可抓区域和接近方向的工具；参考位姿。
- 研究的是：手该去哪、掌心朝哪，是几何信息就够，还是要和站位、躯干姿态一起决定。
- 加一组“站位由参考给、手部目标由 VLM 给”，看两者是否耦合。

## 主导环节是第 5 类（接触后丢失）

- 用实验 2 的空手与持箱偏差，确认执行是否在受载时失真。
- 加一组“事后告诉 agent 物体是否还在手里，允许它重抓”，量出“知道结果并重试”能挽回多少。
- 研究的是：问题在受载执行本身，还是在 agent 不知道已经丢了。

## 两个附加消融（不进主表）

1. 真实感知：把物体位姿真值换成真实深度加 VLM 测量，量出感知误差占多少。
2. 公平性：参与比较的工具各写一页规格并冻结，开发时间设相同上限。
