# 实验 4：单环节替换（门控）

状态：未开始。等实验 3 的失败分布，开会决定替换哪一环。

## 问的是什么

把实验 3 里占比最高的环节换成参考之后，成功率回升多少。只有替换能回答“这一环是不是原因”。

## 做法

对选中的环节，加一个只替换这一环的条件，其余全部由 VLM 和规划器完成，与不替换的基线配对比较。选了两类时，再加一个“两类都替换”的条件。

| 要替换的环节 | 替换成什么 | 需要的额外控制 |
|---|---|---|
| 1 站位或姿态 | 示教的接触前那一帧或那一段 | 标注接触时刻；拼接质检；扰动对照 |
| 2 关键部位的目标 | 由物体真值算出的参考手部位姿和掌心朝向；站位仍由 VLM 给 | 参考位姿的生成规则事先写死 |
| 3 身体没到 | 每条指令后用真实位姿闭环修正到位 | 修正次数上限写死 |
| 4 接触失败 | 手腕到位且合手时，把物体固连到手上 | 固连的到位条件写死 |
| 5 接触后丢失 | 抓起后把物体固连到手上，或把物体质量降到很小 | 两种做法分别报告 |

只在替换第 1 类时需要的两个控制：

- 拼接质检：示教前段接示教后段，失败率不超过 10%（建议值）。不过线先修工程问题。
- 扰动对照：把示教前段的终态在合法范围内加扰动，再接后续流程，成功率不低于示教前段的 80%（建议值）。不过线说明后续流程对站位太敏感，结果不能解读。

## 门控

需同时满足：

- 替换后成功率回升 25 个百分点以上，McNemar p < 0.01。
- 在闭源前沿 VLM 上同样成立。
- 回升不是来自别的环节被顺带修好：替换后，其余四类失败的回合数没有明显下降。

不通过时：

| 现象 | 含义 | 去向 |
|---|---|---|
| 没有任何单一环节回升 25 个点 | 失败分散，没有主导机理 | 止损 |
| 只在开源模型上回升 | 模型能力问题，会随模型变强消失 | 止损 |
| 主导环节是第 3 类 | 执行精度问题 | 导师已否过这一类；如实汇报，由团队决定 |
| 主导环节是第 4 类 | 接触本身 | 这个基准的手只能开合，方法空间窄；评估是否换平台或换题 |

## 盘点时确认的（2026-11-26）

- 替换第 4、5 类要把物体固连到手上，现有代码里没有，要先试能不能做。
- 替换第 3 类的闭环修正，走路的根部修正已有，手腕的没有。
